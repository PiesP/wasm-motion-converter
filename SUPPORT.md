# Support

Thanks for using **dropconvert**! This app converts a single video to GIF/WebP entirely in the browser.

## Questions

Open a [GitHub issue](https://github.com/PiesP/wasm-motion-converter/issues) with
a clear question and enough context to understand the workflow.

## Bug reports

Use the Bug Report template and include:

- Browser + version, OS + device
- Steps to reproduce (clicks/inputs)
- Expected vs. actual result
- Video details (format, codec, resolution, file size)
- DevTools info: `typeof SharedArrayBuffer`, `crossOriginIsolated`, plus console errors

## Feature requests

Open a GitHub issue using the Feature Request template. Describe the workflow and why it helps users.

## Security or privacy issues

Do not file vulnerability details in a public issue. Follow the
[security policy](./.github/SECURITY.md).
